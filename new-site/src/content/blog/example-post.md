This is an example blog post to demonstrate the new Astro-based portfolio site.

## Features

This site supports:

- **Obsidian wikilinks**: Link to other posts with `[[post-name]]`
- **Callouts**: See example below
- **Image galleries**: Multiple images in slideshows
- **Code blocks**: With syntax highlighting

> [!note]
> This is an Obsidian-style callout! It will be beautifully styled.

> [!warning]
> You can use different callout types: note, warning, info, tip, important, caution

## Code Example

```javascript
const greeting = "Hello from Astro!";
console.log(greeting);
```
